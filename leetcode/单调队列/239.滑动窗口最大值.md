# 239. 滑动窗口最大值

## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回滑动窗口中的最大值。

## 示例

示例 1：

输入：`nums = [1,3,-1,-3,5,3,6,7]`, `k = 3`

输出：`[3,3,5,5,6,7]`

解释：

滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7

示例 2：

输入：`nums = [1]`, `k = 1`

输出：`[1]`

示例 3：

输入：`nums = [1,-1]`, `k = 1`

输出：`[1,-1]`

示例 4：

输入：`nums = [9,11]`, `k = 2`

输出：`[11]`

示例 5：

输入：`nums = [4,-2]`, `k = 2`

输出：`[4]`

## 提示

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

## 解题思路

这道题可以使用单调队列来解决。主要思路是维护一个单调递减的双端队列，队列中存储数组元素的索引：

1. 使用双端队列存储数组元素的索引，保持队列中对应元素值单调递减
2. 遍历数组，对于每个元素：
   - 如果队列头部索引超出窗口范围，则移除队列头部
   - 移除队列尾部所有小于当前元素的索引
   - 将当前索引加入队列尾部
   - 当遍历到第 k 个元素后，每次将队列头部对应元素加入结果数组

这种方法的时间复杂度为 O(n)，空间复杂度为 O(k)。

```js
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number[]}
 */
var maxSlidingWindow = function(nums, k) {
    const ans = [];              // 存储结果数组
    const q = new Deque();       // 双端队列，存储数组元素的索引

    // 遍历数组中的每个元素
    for (let i = 0; i < nums.length; i++) {
        // 1. 维护队列单调性 - 右侧入队操作
        // 如果队列非空且队尾元素对应的值小于等于当前值，则移除队尾元素
        // 这样保证队列中的索引按其对应值单调递减排列
        while (!q.isEmpty() && nums[q.back()] <= nums[i]) {
            q.popBack(); // 移除队尾较小元素，维护单调性
        }
        q.pushBack(i); // 将当前元素索引加入队尾

        // 2. 移除窗口外的元素 - 左侧出队操作
        const left = i - k + 1;     // 计算当前窗口的左边界索引
        // 如果队首元素索引小于当前窗口左边界，说明已超出窗口范围
        if (q.front() < left) {
            q.popFront(); // 移除队首过期元素
        }

        // 3. 记录当前窗口的最大值
        // 当窗口完全形成后开始记录结果（left >= 0表示窗口已形成）
        if (left >= 0) {
            // 由于队列单调递减，队首索引对应的元素就是当前窗口最大值
            ans.push(nums[q.front()]); // 将最大值加入结果数组
        }
    }

    return ans; // 返回所有窗口的最大值组成的数组
};
```
